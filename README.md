# <img src="./assets/images/HP.png" width="32" height="32" align="center" /> HighPump - Academia (Landing Page)

<img src="./assets/images/Preview HP.png">

Esta é uma <strong>landing page</strong> moderna e responsiva desenvolvida para simular o ecosistema de uma academia.
Este projeto foi criado com o foco no estudo de <strong>design responsivo</strong>, <strong>performance web</strong> e <strong>boas práticas de UI/UX</strong>.

🔗 <a href="https://high-pump.vercel.app">Acesse o projeto aqui</a>

## ⚙️ Ferramentas Utilizadas
- <strong>HTML5/CSS3</strong>: Estrutura e estilização.
- <strong>JavaScript</strong>: Interatividade.
- <strong><a href="https://github.com/michalsnik/aos">Biblioteca AOS</a></strong>: Animações.
- <strong>Vercel</strong>: Hospedagem.
- <strong>Google Fonts</strong>: Tipografia.

## 📂 Como rodar o projeto localmente
```bash
# Clone o repositório
git clone https://github.com/seu-usuario/high-pump.git

# Entre no diretório
cd high-pump

# Abra o index.html no seu navegador ou use o Live Server
```
